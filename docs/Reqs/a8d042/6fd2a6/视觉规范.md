# 视觉规范 — 实现基础车辆物理系统

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用半透明深色 HUD 叠加于 3D 赛道场景之上，以青色（primary）传达速度与科技感，琥珀色（secondary）用于打滑/警告、红色（danger）用于碰撞，形成清晰的三级状态语义。所有 HUD 元素使用圆角与柔和辉光，保持低信息密度、避免遮挡赛道视野。本工单为纯物理逻辑，HUD 仅作最小可玩反馈，后续可迭代丰富。

# 车辆物理系统 HUD 视觉规格

本工单无页面级 UI，以下为最小可玩反馈 HUD 结构（叠加于 3D 赛道场景之上，均使用 bg_panel 半透明背景 + shadow panel）。

## 1. 速度表 Speedometer
- 位置：屏幕右下角，距右/下边 24px（spacing.lg）
- 背景：bg_panel 半透明深色，radius.md，shadow.panel
- 数值：display 48px，primary 色，右对齐，font-family 使用 typography.family
- 单位 "km/h"：text_dim 12px，紧随数值
- 高速状态（≥45m/s）：数值切换为 secondary 色并叠加 glow_primary

## 2. 油门/刹车指示条 Throttle/Brake Gauge
- 位置：速度表左侧，竖向条 8px × 120px
- 背景：border 半透明，radius.pill
- 油门(+1)：自下而上填充 primary，长度映射油门 0~1
- 刹车/倒车(-1)：自上而下填充 danger，长度映射刹车/倒车深度
- 中性(0)：中央 2px 刻度线，text_dim 色

## 3. 转向指示 Steering Indicator
- 位置：速度表下方，横向条 160px × 6px
- 背景：border 半透明，radius.pill
- 左转(-1)：自中心向左填充 primary；右转(+1)：自中心向右填充 primary
- 中心基准：2px 竖线 text_dim

## 4. 打滑/漂移提示 Drift Indicator
- 触发：车身朝向与速度方向夹角 ≥8° 或抓地力低于阈值
- 显示：屏幕中央偏下，图标 + 文字 "DRIFT"，secondary 色，lg 字号
- 强度映射：打滑程度映射透明度 0.4~1.0 及 glow_primary 强度
- 动效：出现 150ms fade-in，消失 300ms fade-out

## 5. 碰撞反馈 Collision Feedback
- 触发：边界碰撞瞬间
- 全屏：danger 色径向光晕，透明度 0~0.35，100ms 内衰减消失
- 速度表：数值 300ms 内抖动（scale 1.0 → 1.08 → 1.0）
- 冷却：碰撞后 500ms 内不重复触发

## 6. 赛道边界 Boundary Visual
- 护栏/路肩：与碰撞检测区域一致，边框高亮 danger 色
- 碰撞区域：半透明 danger 高亮，仅调试模式可见
## 精灵图规格
- 轮胎烟尘 drift_smoke：单帧 64×64，8 帧（2×4 布局），灰白 alpha 渐隐循环，用于高速打滑粒子发射器
- 碰撞火花 collision_spark：单帧 32×32，4 帧（1×4 布局），橙白 alpha 渐隐单次播放，用于边界碰撞反馈
- 漂移图标 icon_drift：单帧 48×48，静态 outline 图标，secondary 色，用于打滑提示
