# PRD — 实现基础车辆物理系统

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 用户故事
作为一名玩家，我想要驾驶一辆具备基础物理（加减速、转向、速度相关抓地力）的赛车，以便在高速转向时感受到打滑、在碰撞赛道边界时感受到减速，从而获得流畅且可预期的驾驶手感，顺利完成单圈计时验证。

## 功能需求
1. 加速：按住 W/↑ 时车辆持续加速，速度随时间递增，直至达到最大前进速度；加速曲线连续无突变。
2. 减速/刹车：按住 S/↓ 时车辆减速；速度降至 0 后继续按住进入倒车，倒车拥有独立的最大速度上限（低于前进最大速度）。
3. 自然减速：松开加速键后，车辆受滚动阻力/空气阻力影响自然减速至 0。
4. 转向：按住 A/D/←→ 时，车辆按当前速度以对应角速度转向；低速转向半径小、响应快，高速转向半径大、响应慢。
5. 速度相关抓地力：车辆抓地力随速度降低；高速状态下转向产生侧向滑动（打滑/漂移），速度越高侧滑越明显。
6. 边界碰撞减速：车辆与赛道边界（护栏/路肩外侧）碰撞时，速度按比例衰减，并触发短暂碰撞冷却，防止连续扣速。
7. 参数可配置：加减速、极速、转向灵敏度、抓地力衰减曲线、碰撞减速比例等全部物理参数集中收敛于共享配置对象，便于调参。

## 验收标准
1. 静止状态下按住 W，车辆在 4s 内从 0 加速至最大前进速度（60m/s），加速过程速度曲线连续、无跳变。
2. 达到最大速度后松开 W，车辆在 2s 内自然减速至 0（无刹车介入）。
3. 行驶中按住 S，车辆在 1.5s 内从当前速度减速至 0；继续按住 S，在 1s 内倒车加速至最大倒车速度（≤15m/s）。
4. 低速（≤20m/s）按住 A/D，车辆在 0.5s 内开始转向，转向角速度 ≥1.5rad/s，且车身朝向与速度方向夹角 ≤5°（无侧滑）。
5. 高速（≥45m/s）按住 A/D，车辆产生可感知侧滑，车身朝向与速度方向夹角 ≥8°，且抓地力随速度单调递减（速度越高夹角越大）。
6. 车辆与赛道边界碰撞后，速度在 100ms 内衰减至碰撞前的 30%~50%，且碰撞后 500ms 内不重复触发扣速（冷却）。
7. 全程驾驶过程帧率 ≥60fps，单帧耗时 ≤16.7ms，物理更新与渲染无可见卡顿。
8. 物理更新采用固定时间步长（与帧率解耦），在不同刷新率（60Hz/120Hz）下车辆加速、转向、碰撞表现一致（同一输入序列下行驶轨迹误差 ≤1%）。

## 边界条件（不做的事）
1. 不包含：悬架、轮胎形变、真实轮胎摩擦圆（Pacejka 模型）等高级物理模型。
2. 不包含：车辆碰撞形变、翻车、损毁系统。
3. 不包含：多车 AI、联网同步、排行榜。
4. 不包含：漂移积分、氮气加速、道具系统。
5. 不包含：草地/沙地等地形摩擦差异，本工单仅实现赛道边界碰撞减速。
6. 不包含：触屏虚拟按键 UI 的绘制与布局，本工单只负责物理层对外提供输入/输出接口，触屏输入映射由后续工单实现。
7. 不包含：手柄/方向盘等外设输入支持。
