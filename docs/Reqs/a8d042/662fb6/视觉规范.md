# 视觉规范 — 实现基础游戏 UI

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用深色科幻扁平风（Tech Flat）：深蓝黑半透明面板 + 霓虹青色（#00E5FF）作为核心强调色，营造未来感赛道驾驶氛围，避免拟物与高饱和堆砌。HUD 遵循低信息密度原则，只保留速度、圈数、计时三类核心数据，所有数值用等宽字体（tabular-nums）保证稳定无跳动，只读面板 pointer-events 穿透不干扰 3D 渲染。可交互层（开始/结算/触屏按键）用高对比按钮与半透明遮罩突出层级，触屏按键遵循移动端最小可点击尺寸，确保键盘与触屏体验一致。

## 组件视觉规范

# 组件视觉规格 — WebRacing3D 基础游戏 UI

## 全局
- 视觉风格：科幻扁平风（Tech Flat），深色背景 + 霓虹青色主色，避免拟物，控制 HUD 信息密度。
- 字体：数字/数值统一使用等宽字体（mono），标题与按钮使用 display 字体；标签使用 body 字体。
- 所有 HUD 只读面板 `pointer-events: none`，确保不阻挡 3D canvas 交互。
- 安全边距：`screen_margin` 24px（触屏设备需考虑刘海/圆角，可用 `env(safe-area-inset-*)`）。

## 1. HUD 圈数面板（顶部左）
- 容器：`bg_panel` 半透明深色背景，1px `panel_border` 边框，`radius.panel` 圆角，`shadow.panel`。
- 内边距 `panel_pad` 16px，垂直居中对齐。
- 标签「圈数」：`text_secondary`，`hud_label` 12px，`letter_spacing_hud`。
- 数值「当前圈 / 总圈数」：`lap_current`(当前) + `lap_total`(总数)，`hud_lap_value` 28px，`font_weight_bold`，mono。
- 状态：跨过终点当前圈 +1 时，当前圈数字闪烁一次（`text_glow` 高亮 200ms）作为反馈。

## 2. HUD 计时器面板（顶部中/右）
- 容器样式同圈数面板，右对齐。
- 标签「本圈时间」：`text_secondary`，`hud_label` 12px。
- 数值「分:秒.毫秒」：`timer_value` 白色，`hud_timer_value` 32px，mono，`font_weight_semibold`。
- 毫秒 3 位固定宽度（用 `font-variant-numeric: tabular-nums`），避免数字跳动。
- 分、秒、毫秒冒号分隔符用 `text_muted` 弱化。

## 3. HUD 速度表面板（底部中央）
- 容器：`bg_panel`，`radius.panel`，`shadow.panel`，底部居中，内边距 `panel_pad`。
- 数值：`speed_value` 青色，`hud_speed_value` 64px，`font_weight_bold`，mono，整数显示（无小数）。
- 单位「km/h」：`speed_unit`，`hud_speed_unit` 16px，紧随数值右下角。
- 可选倒车标识：速度为负/倒车时，数值旁显示「R」小徽章（`danger` 色，`radius.sm` 圆角背景），或用 `danger` 色数值提示；确保不显示 NaN/负值。

## 4. 开始界面（全屏遮罩）
- 遮罩：`bg_overlay` 半透明深色，铺满视口，`z-index` 高于 HUD，可接收点击。
- 居中容器：`bg_panel` + `panel_border` + `radius.xl` + `shadow.modal`，内边距 `xxl` 48px，最大宽度 480px。
- 标题（游戏名「WebRacing3D」）：`text_primary`，`title` 40px，`font_weight_bold`，`letter_spacing_title`，可选 `text_glow`。
- 副标题/说明文案：`text_secondary`，`subtitle` 16px，`text-align: center`。
- 主按钮「开始」：见按钮规格。

## 5. 结算界面（全屏遮罩）
- 遮罩与容器样式同开始界面。
- 标题「单圈完成」：`success` 或 `primary` 色，`xl` 20px 起，`font_weight_bold`。
- 成绩展示：标签「本圈时间」+ 数值，数值用 `result_time` 44px mono，`primary` 色，与计时器最终值一致。
- 主按钮「重新开始」：见按钮规格（主操作样式）。

## 6. 按钮（开始 / 重新开始）
- normal：`primary` 背景，`text_primary` 文字，`button` 18px，`font_weight_semibold`，`radius.button` 圆角，`shadow.button`，内边距 `button_pad_y` 14px / `button_pad_x` 36px。
- hover：`primary_hover` 背景，`shadow.button_hover`。
- pressed：`primary_pressed` 背景，轻微缩放 (scale 0.98)。
- disabled：`text_muted` 文字 + 50% 透明度背景，`cursor: not-allowed`。
- 最小可点击区域 ≥ 44×44px（触屏友好）。

## 7. 触屏虚拟按键（仅移动端）
- 仅在触摸设备（`(pointer: coarse)`）显示，`z-index` 高于 HUD，可接收 pointer 事件。
- 布局：左侧左/右转向键，右侧加速键 + 刹车键；每组内 `touch_key_gap` 16px 间距，距屏幕边 `screen_margin`。
- 按键：`touch_key_bg` 背景，`touch_key_border` 1px 边框，`radius.touch_key` 圆角，尺寸 `touch_key_size` 72px（触屏最小 60px 以上）。
- 图标/文字：`text_primary`，居中，`xl` 字号（加速「+」/「A」、刹车「−」/「B」、转向「◀」「▶」）。
- active（按下）：`touch_key_active` 背景高亮，`touch_key_active` 内描边，支持长按。
- 语义标签：`aria-label` 明确（加速/刹车/左转/右转）。

## 8. 状态色说明
- 成功/结算：`success`。
- 警示/倒车：`danger`。
- 强调/数值：`primary`。
- 弱化/分隔符：`text_muted`。
