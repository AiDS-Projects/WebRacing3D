# PRD — 实现基础游戏 UI

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 用户故事
As a 玩家，I want 在驾驶过程中实时看到速度表、当前圈数与单圈计时器，并在进入游戏前有开始界面、完成一圈后有结算/重置入口，So that 我能直观掌握驾驶状态并随时开始或重新开始比赛。

## 功能需求
- HUD 速度表：以整数 km/h 显示实时速度，数据来源于既有物理系统（通过 service/store action 读取，禁止组件内直接改 store 或重复计算）。\n- 当前圈数：显示「当前圈 / 总圈数」，圈数变化来自既有计时与圈数系统，UI 只做展示与订阅。\n- 计时器：以「分:秒.毫秒」格式显示当前单圈计时，跨过终点时结算本圈成绩。\n- 开始界面：进入页面后显示开始界面（标题 + 「开始」按钮），点击后隐藏并进入驾驶状态。\n- 结算/重置界面：完成一圈后显示单圈成绩与「重新开始」按钮；重置须恢复初始圈数/计时/速度等全部状态。\n- 触屏虚拟按键：移动端提供加速/刹车/转向虚拟按键，与键盘输入（W/↑、S/↓、A/D/←→）等价接入同一输入 service。\n- 端到端联调：UI 与物理、计时、赛道模块联调，确保读取的数据源一致。\n- Playwright 截图验收：提供可重复执行的截图用例，覆盖开始界面、驾驶中 HUD、结算界面三种状态。\n- 实现遵循 TypeScript 规范：无 any、外部数据运行时校验、共享逻辑沉淀到 utils/services。

## 验收标准
- [ ] 页面加载完成后 1000ms 内显示开始界面，包含标题文案与「开始」按钮，且按钮可点击。\n- [ ] 点击「开始」后 300ms 内开始界面隐藏，HUD（速度表、圈数、计时器）全部可见。\n- [ ] 速度表显示值随物理速度实时变化，刷新率 ≥ 30 次/秒，与物理系统速度值偏差 ≤ 1 km/h。\n- [ ] 速度表数值为整数 km/h，无 NaN/负值显示异常（倒车时显示 ≥ 0 的合理值或明确倒车标识）。\n- [ ] 圈数显示初始为「1 / 1」（或约定总圈数），赛车通过起点线后当前圈数立即 +1，延迟 ≤ 100ms。\n- [ ] 计时器以「分:秒.毫秒」格式（毫秒 3 位）持续递增，与真实时间误差 ≤ 50ms/10s。\n- [ ] 完成一圈通过终点后 500ms 内显示结算界面，单圈成绩与计时器最终值一致（误差 ≤ 50ms）。\n- [ ] 结算界面点击「重新开始」后 300ms 内恢复：计时归零、圈数重置为初始值、速度归零、赛车回到起点。\n- [ ] 键盘 W/↑ 加速、S/↓ 刹车/倒车、A/D/←→ 转向；触屏虚拟按键按下/松开与键盘行为一致（长按加速、松开停止加速）。\n- [ ] 驾驶全程帧率 ≥ 60fps（目标），在 1920×1080 下无明显卡顿（帧时间 > 50ms 的帧占比 < 1%）。\n- [ ] Playwright 截图用例可无头运行，成功产出开始界面、驾驶中 HUD、结算界面三张截图且关键 UI 元素可见。\n- [ ] 全部验收项通过类型检查与 lint，代码中无 any 类型、无直接修改 store 属性。

## 边界条件（不做的事）
- 不包含：后端/账号/登录/存档，纯单机本地运行。\n- 不包含：音效、背景音乐、粒子特效等表现层内容。\n- 不包含：小地图、排行榜、多圈成绩历史记录。\n- 不包含：暂停菜单、设置界面、音量/画质调节。\n- 不包含：多语言切换，文案以中文为准。\n- 不包含：赛道选择/车辆选择，固定单圈路线与单一赛车。\n- 不包含：联机对战与网络同步。\n- 触屏虚拟按键仅在移动端（触摸设备）显示，桌面端不强制显示。

## 资产需求线索
- 图标：开始/重新开始按钮图标（可用 CSS/矢量图形实现，无需位图）。\n- 图片：暂无（HUD 用 CSS/DOM 元素绘制，避免额外纹理加载）。\n- 字体：数字显示建议使用等宽/数字字体（如 monospace 或系统自带 tabular-nums），确保计时器数字不抖动。\n- 音效：暂无。\n- 动画：开始界面到驾驶状态的过渡（≤ 300ms 淡入/淡出）可选，非必须。\n- 粒子/骨骼：暂无。
