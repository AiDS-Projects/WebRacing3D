# 视觉规范 — 初始化项目脚手架与技术栈

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用暗色科幻赛车 HUD 风格：深蓝黑底色（#0A0E14）搭配电光青（#00E5FF）主强调色，营造速度与科技感。UI 元素以半透明深色浮层 + 细边框呈现，保持高信息密度但克制装饰，避免遮挡 Three.js 渲染画布。开发调试类浮层（DebugOverlay）使用等宽字体与霓虹描边，突出工程化与可读性，为后续 HUD、计时、速度表等玩法 UI 预留统一视觉基调。

## 组件视觉规范

# 组件视觉规格

## 1. GameViewport 游戏视口容器
- 定位：固定定位，占满 100vw × 100vh，`z-index: 0`
- 背景色：`bg #0A0E14`（Three.js 场景底色，未渲染时兜底）
- 内容：仅承载 `<canvas>`，无边框、无内边距
- canvas：`display: block`，宽高 100%，避免内联元素间隙

## 2. DebugOverlay 调试信息浮层（仅开发环境）
- 定位：`position: fixed; top: 16px; left: 16px; z-index: 100`
- 背景色：`overlay rgba(10,14,20,0.72)` 半透明深色条
- 边框：1px solid `border #2A3444`
- 圆角：`radius.md 8px`
- 阴影：`shadow.debugBar`
- 内边距：`spacing.sm 8px` / `spacing.md 16px`
- 字体：`typography.mono` 等宽字体，字号 `sm 12px`
- 文本色：FPS 数值用 `primary #00E5FF`，帧耗时标签用 `textMuted #8B98A9`
- 状态色：FPS ≥ 55 用 `success #00E676`，30–55 用 `warning #FFB300`，< 30 用 `error #FF5252`
- 交互：`pointer-events: none`，不可点击/拖拽

## 3. BootOverlay 初始化遮罩层
- 定位：`position: fixed; inset: 0; z-index: 200`，覆盖整个视口
- 背景色：`bg #0A0E14` 不透明，初始化期间全遮
- 内容：居中 Loading 文本『场景初始化中…』
- 字体：`typography.sans`，字号 `lg 16px`，颜色 `textMuted #8B98A9`
- 动效：渲染器就绪后淡出（opacity 1→0，时长 300ms），淡出后移除节点

## 4. ErrorOverlay 错误提示浮层
- 定位：`position: fixed; inset: 0; z-index: 300`，`display: flex` 居中
- 背景遮罩：`overlay rgba(10,14,20,0.72)`
- 卡片：背景 `bgElevated #141A24`，边框 1px solid `border #2A3444`，圆角 `radius.lg 12px`
- 卡片阴影：`shadow.overlayCard`
- 内边距：`spacing.lg 24px`，最大宽度 420px
- 标题：『渲染初始化失败』，字号 `heading 20px`，颜色 `error #FF5252`
- 正文：错误原因文案，字号 `base 14px`，颜色 `text #E6EDF3`
- 重试按钮：背景 `primary #00E5FF`，文字 `bg #0A0E14`，圆角 `radius.md 8px`，内边距 `8px 16px`
- 按钮 hover：背景 `primaryDim #00B8D4`
- 按钮 active：亮度再降 10%
## 精灵图规格
本工单为项目脚手架搭建，暂不涉及游戏玩法精灵图资产，game_sprite_spec 置空。后续赛道/赛车/物理模块开发时，需补充：车辆轮胎烟雾粒子精灵（64×64，8 帧循环）、速度线/加速拖尾精灵（128×128，4 帧）、UI 按钮 hover 高亮九宫格切图（48×48，3 状态）。
