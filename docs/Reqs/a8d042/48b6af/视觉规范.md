# 视觉规范 — 初始化项目脚手架与技术栈

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用「科幻霓虹 + 深空暗色」风格：深蓝黑背景配电光青（cyan）主色与霓虹粉红（magenta）强调色，营造高速竞速的科技氛围。UI 以扁平化为主，关键交互元素使用霓虹辉光与斜切边角点缀，避免像素风，保持现代科幻赛车游戏质感。信息密度克制：脚手架阶段仅保留加载、按钮、反馈与空状态等基础组件，HUD 区域预留高可读性的等宽数字字体。

## 组件视觉规范

# 组件视觉规格

## 1. 加载页 Loading Screen
- 背景：全屏 `bg #0A0E1A`，覆盖一层轻微径向渐变提亮中心（`surface #111827` → `bg`）
- 中心元素：赛车 logo/占位图 + 加载进度条
- 进度条：轨道 `surface #1A2332`，圆角 `radius.md 8px`，高 4px；填充 `primary #00D4FF`，带 `shadow.neonPrimary` 辉光
- 文案：`textSecondary #9AA6B8`，字号 `sm 12px`，使用 `monoFamily`
- 转场：淡入淡出，进度 0→100% 后 200ms 内消失

## 2. 按钮 Button
- 正常（normal）：背景 `primary #00D4FF`，文字 `bg #0A0E1A`，字重 `semibold`，圆角 `radius.md 8px`，内边距 `spacing.sm 8px` 垂直 / `spacing.lg 24px` 水平
- hover：背景 `primaryHover #33DEFF`，轻微上移 1px，加 `shadow.neonPrimary`
- active：背景 `primaryActive #00B4D8`，取消位移
- loading：背景不变，禁用点击，图标替换为 16px 旋转 loading 圆环（`primary` 色），文字保留
- disabled：背景 `surface #1A2332`，文字 `textMuted #5A6478`，无阴影，`cursor: not-allowed`
- 次按钮（secondary）：透明背景，边框 1px `border #2A3446`，文字 `text #F2F5FA`；hover 边框变 `primary`，文字变 `primary`

## 3. 反馈区 Toast
- 容器：`surfaceElevated #1A2332`，圆角 `radius.md 8px`，左边框 3px 状态色，`shadow.card`
- 成功：左边框 `success #2EE6A8`；错误：`error #FF4D4F`；警告：`warning #FFB020`；信息：`primary #00D4FF`
- 文字：`text #F2F5FA`，字号 `base 14px`；辅助行 `textSecondary` 字号 `sm 12px`
- 位置：视口右上角，间距 `spacing.lg 24px`，堆叠间隔 `spacing.sm 8px`
- 动画：从右侧滑入 240ms，停留 3s，淡出 200ms

## 4. 空状态 Empty State
- 容器：居中，最大宽 400px，间距 `spacing.lg 24px`
- 插画：`empty_state` 400x300，位于文案上方
- 标题：`heading 20px`，`text #F2F5FA`，字重 `semibold`
- 描述：`base 14px`，`textSecondary #9AA6B8`
- 操作按钮：跟随按钮规格（primary），置于描述下方

## 5. HUD 占位条（预留）
- 底部信息条：半透明 `surface` 背景 + `overlay`，圆角 `radius.lg 12px`
- 数据项：标签 `textMuted #5A6478` 字号 `sm`，数值 `text #F2F5FA` 字号 `hudMono 18px` 使用 `monoFamily`，霓虹 `primary` 高亮关键指标
- 边角：斜切（chamfer）描边，贴合科幻赛车 HUD 风格
## 精灵图规格
本工单为脚手架阶段，无玩法精灵图需求。预留以下竞速 HUD 精灵图规格供后续 physics/ui 模块使用：
1. id: hud_speed_digits | 尺寸: 320x64 | 帧数: 1（单帧） | 动画: 无 | 用途: 速度数字面板
2. id: hud_boost_bar | 尺寸: 256x32 | 帧数: 1 | 动画: 无（填充由代码控制） | 用途: 氮气/加速条轨道
3. id: hud_minimap_frame | 尺寸: 256x256 | 帧数: 1 | 动画: 无 | 用途: 小地图外框
4. id: btn_icon_play | 尺寸: 48x48 | 帧数: 3 | 动画: 空闲/悬停/按下三态 | 用途: 播放按钮三态图（可选，与 icon 方案二选一）
