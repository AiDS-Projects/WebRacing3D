# 视觉规范 — 初始化项目脚手架与技术栈

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用「深空黑底 + 电光青强调」的极简科幻风，贴合 3D 竞速游戏的科技感与高速感。界面以纯渲染画布为绝对主体，仅保留半透明遮罩的加载层与错误层，信息密度极低、克制留白。后续 HUD 元素沿用同一套青色主色、深色卡片与发光描边的视觉语言，保证脚手架阶段建立的视觉基调可持续扩展。

## 组件视觉规范

# 组件视觉规格

## 1. Canvas 渲染层（底层）
- **位置/尺寸**：`position: fixed`，铺满全视口 `100vw × 100vh`，`z-index: 0`
- **背景**：`#0A0E17`（WebGL 渲染前兜底色，避免白闪）
- **渲染内容**：Three.js 场景（Scene + PerspectiveCamera + WebGLRenderer 输出的画布）
- **画布自适应**：`display: block`，尺寸由 renderer 随窗口 resize 同步更新，禁止 CSS 拉伸（保持像素比与宽高一致，防止变形）
- **无边框、无阴影**，纯渲染层不承载交互

## 2. LoadingOverlay（中层遮罩）
- **位置/尺寸**：`position: fixed` 全屏覆盖，`z-index: 10`，`display: flex` 垂直居中
- **背景**：`rgba(10, 14, 23, 0.72)`（半透明遮罩，避免暴露未初始化黑屏）
- **内容布局**：垂直居中，spinner 在上，状态文案在下，间距 `16px`
- **Spinner**：纯 CSS 旋转圆环，直径 `40px`，边框 `3px solid rgba(34, 211, 238, 0.16)`，顶部 `3px solid #22D3EE`，动画 `spin 0.8s linear infinite`
- **状态文案**：字体 `Inter 14px/400`，颜色 `#9CA3AF`，文案「初始化中…」；ready 态淡出 `opacity 0.3s ease` 后 `pointer-events: none` 移除
- **状态**：`init`（显示）→ `ready`（淡出移除，`transition: opacity 300ms`）

## 3. ErrorOverlay（错误提示层）
- **位置/尺寸**：`position: fixed` 全屏覆盖，`z-index: 20`，`display: flex` 垂直水平居中
- **背景**：`rgba(10, 14, 23, 0.88)`（更深遮罩，突出错误）
- **卡片容器**：背景 `#111827`，边框 `1px solid #2A3444`，圆角 `12px`，阴影 `shadow.lg`，内边距 `32px`，最大宽度 `360px`，居中
- **错误图标**：48px 告警图标，颜色 `#EF4444`，居中
- **标题**：`Inter 22px/700`，颜色 `#E5E7EB`，文案「WebGL 初始化失败」/「运行时错误」
- **描述**：`Inter 14px/400`，颜色 `#9CA3AF`，行高 `1.5`，上间距 `8px`
- **重试按钮**：背景 `#22D3EE`，文字 `#06121A`（`Inter 14px/500`），圆角 `8px`，内边距 `8px 24px`，上间距 `24px`；hover 亮度 `+8%`，active 下移 `1px`；focus 边框 `1px solid #22D3EE`

## 4. 状态指示角标（可选，调试期显示）
- **位置**：右上角，`z-index: 5`，距边缘 `16px`
- **样式**：胶囊背景 `rgba(17, 24, 39, 0.8)`，边框 `1px solid #2A3444`，圆角 `pill`，内边距 `4px 12px`
- **文字**：`JetBrains Mono 12px`，颜色 `#34D399`，文案「初始化完成」
## 精灵图规格
本工单为脚手架验证，无玩法角色、车辆或 HUD 精灵需求，暂不产出精灵图。预留约定：后续车辆/UI 精灵统一采用像素对齐导出，帧动画按 (宽 × 高 × 帧数) 标注，如 128x128x8；动画序列以 60fps 或 30fps 采样，命名遵循 `prefix_animation_framenum`。
