# 视觉规范 — 构建 3D 环形赛道场景

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用「深色扁平游戏 HUD」风格：3D 场景使用高对比度占位材质（深灰路面、红白路肩、金属灰护栏、绿色草地），确保赛道边界在俯瞰与跟随视角下清晰可辨。UI 层为半透明深色玻璃面板配青色霓虹强调色，层次分明且不遮挡赛道视野。调试数据使用等宽字体呈现，强调「工程原型」的可读性与可验收性，为后续车辆与计时功能接入预留一致的视觉基调。

## 组件视觉规范

# 组件视觉规格

## 1. 游戏视口 Viewport（全屏 3D 画布）
- 背景：场景草地色 `#3E7C3A`，渲染器 clearColor 同色，避免加载闪烁
- 尺寸：占满全屏 `100vw x 100vh`
- 无边框、无内边距，承载场景对象，不渲染任何 DOM 交互控件

## 2. 顶部 HUD 栏
- 布局：`position: fixed; top: 0`，横向 flex，左右两端对齐
- 背景：透明底（无底色），内容加文字阴影保证可读
- 内边距：`16px 24px`
- 左侧标题：`heading 20px`，颜色 `#E8ECF1`，字重 600，文字阴影 `0 1px 4px rgba(0,0,0,0.6)`
- 右侧按钮组：图标按钮 40x40，圆角 `md 8px`，背景 `panel_bg`，边框 `1px solid panel_border`
- 按钮 hover：背景提亮 `rgba(255,255,255,0.08)`
- 按钮 active：`scale 0.95` + 边框变 `primary`
- 按钮 disabled：`opacity 0.45`，`cursor: not-allowed`

## 3. Loading 遮罩层
- 布局：全屏覆盖，`position: fixed; inset: 0`，背景 `bg_overlay` + 轻微 backdrop-blur `4px`
- 内容：居中 flex column，spinner + 文案
- Spinner：48x48 环形转圈，边框 `3px`，颜色 `primary`，1s 线性无限旋转
- 文案：`lg 16px`，颜色 `text`，进度百分比用 `mono 13px` 显示
- 状态：生成完成后淡出（opacity 过渡 300ms）

## 4. 调试面板（右侧抽屉）
- 布局：`position: fixed; right: 0; top: 64px; bottom: 64px`，宽度 320px
- 背景：`panel_bg`，左边框 `1px solid panel_border`，圆角左侧 `lg 12px`
- 阴影：`shadow.panel`
- 标题区：`heading 20px`，颜色 `text`，底部 `1px solid panel_border` 分隔
- 数据标签：`sm 12px`，颜色 `text_muted`
- 数据值：`mono 13px`，颜色 `text`，右对齐
- 状态色：通过 `success #34D399`，失败 `error #FF5A5F`，警告 `warning #FBBF24`
- 折叠态：收起为 40px 宽竖条，显示纵向图标按钮

## 5. 错误/空状态面板（居中弹窗）
- 布局：居中弹窗，宽度 420px，背景 `panel_bg`，圆角 `lg 12px`，边框 `1px solid panel_border`，阴影 `shadow.panel`
- 图标：48x48，颜色 `error #FF5A5F`
- 标题：`heading 20px`，颜色 `text`
- 说明文案：`base 14px`，颜色 `text_muted`
- 按钮：主按钮背景 `primary`，文字深色 `#0A0C10`，圆角 `md 8px`，hover 用 `primary_hover`，active 用 `primary_active` + `scale 0.95`

## 6. 场景对象占位材质
- 路面 Road：`scene_road #3A3F47`，粗糙度高，无高光
- 路面边缘线：白色 `#FFFFFF`，宽 0.2m，沿路面两侧
- 路肩 Curb：红白交替 `#E53935` / `#F5F5F5`，每段 1m
- 护栏 Guardrail：`scene_guardrail #8C929B`，顶部加白色反光条
- 草地 Grass：`scene_grass #3E7C3A`，无纹理
- 起点线：黑白棋盘格程序化纹理 `#16181C` / `#FFFFFF`，宽 1m

## 精灵图规格
本工单为纯程序化几何与占位材质场景，无需传统 2D 精灵图动画。唯一需要的是起点线黑白棋盘格纹理（128x128，2 帧 4x4 棋盘，无动画），通过 Canvas 程序化生成而非外部资源。Loading spinner 与 UI 图标均由 CSS/Iconify 矢量实现，不涉及帧动画精灵。
