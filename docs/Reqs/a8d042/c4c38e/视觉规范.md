# 视觉规范 — 构建 3D 环形赛道场景

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用深色科幻赛车 HUD 风格：3D 场景以低饱和纯色基础材质区分功能区域（深灰路面、红白路肩、银白护栏、草绿草地），强调几何体边界清晰、无纹理干扰。UI 层采用半透明深色面板 + 高亮蓝色主色 + 等宽字体呈现数据，突出信息可读性与速度感，与 3D 场景形成统一的暗色高对比视觉体系。

## 组件视觉规范

# 3D 环形赛道场景 — 组件视觉规格

## 1. 赛道路面 (Road)
- 几何：沿中心线拉伸的闭合带状体，宽 12m，厚 0.2m
- 材质：MeshStandardMaterial，深灰 #3A3A3E，roughness 0.9，metalness 0.0
- 视觉：无纹理纯色，表面粗糙以体现光照方向，无断点/交叉/重叠

## 2. 路肩 (Curb)
- 几何：路面两侧各一条，宽 1.5m，厚 0.15m（略高于路面 0.05m）
- 材质：MeshLambertMaterial，红白相间（红 #D64545 / 白 #F5F5F5），每段 2m 交替
- 视觉：高对比红白条纹，作为赛道边缘视觉标识，连续覆盖整圈无缺口

## 3. 护栏 (Guardrail)
- 几何：沿中心线两侧等距立柱 + 横杆，高 1m，柱间距 ≤5m
- 材质：MeshStandardMaterial，银白 #C8CDD4，roughness 0.4，metalness 0.6
- 视觉：形成赛道物理边界，与深灰路面、绿色草地形成明度分层

## 4. 草地 (Grass)
- 几何：覆盖赛道包围盒 + 四周各 50m 边距的平面
- 材质：MeshLambertMaterial，草绿 #5C8A3C，无纹理
- 视觉：低饱和绿色，作为背景衬托赛道主体

## 5. 起点/终点线 (Start Line)
- 几何：中心线 index 0 处横向标线，横跨路面宽 12m，宽 0.5m
- 材质：纯白 #FFFFFF，高于路面 0.01m（防 z-fighting）

## 6. Loading 加载层
- 背景：全屏遮罩 #0D1117 不透明度 0.92
- 进度条：高 6px，圆角 pill，轨道 #30363D，填充 #4F8CFF
- 文案：'正在构建环形赛道…'，#E6EDF3，16px，居中
- 底部版本小字：#8B949E，11px

## 7. HUD 信息区（左上）
- 背景：半透明 #161B22 不透明度 0.85，圆角 8px，内边距 12px，阴影 hud
- FPS 计数器：等宽字体 13px，正常 #3FB950 / 低于 60 #D29922
- 赛道状态徽标：圆角 pill，采样点数 #E6EDF3，闭合成功 #3FB950 / 失败 #F85149

## 8. 调试按钮（右上）
- 图标：齿轮 debug-panel 24px outline，默认 #8B949E，hover #E6EDF3
- 背景：圆形 #161B22 不透明度 0.85，40px，阴影 hud

## 9. 调试面板 (Debug Panel)
- 背景：#161B22 不透明度 0.95，圆角 12px，阴影 panel
- 标题：16px #E6EDF3；数据行：标签 #8B949E 12px / 值 #E6EDF3 14px 等宽
- 校验项状态色：通过 #3FB950，失败 #F85149
## 精灵图规格
暂无：本工单赛道为程序化 Three.js 几何体（MeshStandardMaterial/MeshLambertMaterial 纯色），无精灵图/帧动画需求。起点线如需黑白格纹理，可后续用程序化 CanvasTexture 生成，当前非必需。
