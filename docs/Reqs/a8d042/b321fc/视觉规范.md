# 视觉规范 — 实现计时与圈数系统

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用「科幻竞速 HUD」风格：深色半透明面板叠加在 3D 赛道之上，信息以高对比等宽数字（monospace）呈现，保证高速驾驶下的可读性。主色使用电光青 (#00E5FF) 作为计时与速度的功能色，成功态以荧光绿 (#00FF88) 传达「单圈完成」的正向反馈，红色仅用于反向/异常警示。视觉强调轻盈、克制的信息密度——单屏仅承载计时器、圈数、速度三组核心数据，配以细边框与柔和光晕营造仪表感，避免遮挡赛道视野。

## 组件视觉规范

# 组件视觉规格 — 计时与圈数系统

## 1. 计时器 HUD（TimerHUD）
- **位置**：屏幕顶部居中，HUD 顶栏内，距顶 20px。
- **背景**：`bg_hud` 半透明深色底衬，圆角 `md`(8px)，内边距 8px 12px，`shadow.hud`。
- **字体**：`family_mono`，字号 `timer`(40px)，`tabular_nums` 等宽数字防止抖动。
- **文本颜色**：READY/RACING 状态用 `primary`(#00E5FF) + `text_glow` 微光晕；FINISHED 冻结态切换为 `success`(#00FF88)。
- **格式**：`MM:SS.mmm`，毫秒位字号略小（28px）、透明度 0.85 做层级区分。
- **状态徽标**：左侧小圆点（6px），READY 灰白 `neutral`、RACING `primary` 呼吸脉冲、FINISHED `success`。

## 2. 圈数显示（LapCounter）
- **位置**：计时器正下方 6px，同底衬内。
- **字体**：`family_display`，字号 `lap`(18px)，`letter_spacing_wide`。
- **文案**：READY →「第 1 圈」；RACING →「第 1 圈 · 计时中」；FINISHED →「已完成 1 圈」。
- **文本颜色**：`text_dim`(#C7D2E8)，圈数数字用 `text`(#FFFFFF) 高亮。

## 3. 速度表（Speedometer）
- **位置**：屏幕右下角，距底/右 20px。
- **背景**：同 `bg_hud` 底衬，圆角 `lg`(12px)。
- **字体**：`family_mono`，字号 `speed`(32px)，`tabular_nums`。
- **结构**：左侧大数字（km/h），右侧竖排小字「SPEED」标签（`xs`，`neutral`）。
- **颜色**：常态 `text`(#FFFFFF)，速度值带 `primary` 左侧竖条装饰（3px 宽）。

## 4. 结算面板（ResultPanel）
- **布局**：全屏模态，背景 `bg_backdrop` 遮罩 + 中央面板。
- **面板**：`bg_panel`，圆角 `panel`(16px)，内边距 `panel_pad`(28px)，`shadow.panel`，入场动画 `motion.panel_in`（从 0.92 缩放 + 淡入）。
- **标题**：「单圈完成」`family_display` 字号 `panel_title`(24px)，`success` 色。
- **成绩**：大号 `family_mono` 字号 `panel_laptime`(48px)，`success` + `glow_success`，格式 `MM:SS.mmm`。
- **「重新开始」按钮**：主按钮，`primary` 底色渐变（`primary`→透明 15%）、白字 `family_display` `lg`(18px)、圆角 `md`(8px)、hover 提亮 + `glow_primary`；内嵌重启图标（左侧 16px）。

## 5. 状态提示条（StateBanner，可选轻提示）
- RACING 启动瞬间顶部短暂显示「GO」大字 400ms 后淡出；FINISHED 同位置「FINISH」。
- 字体 `family_display`，`success`/`primary` 色，带 `text_glow`，入场淡入淡出 160ms。

## 6. 起终点检测线（3D 地面标线）
- **实现**：赛道横跨的扁平几何平面（贴地、略高于路面 0.5cm 防 Z-fighting）。
- **纹理**：黑白棋盘格（`checker_black`/`checker_white`），2 行 x 8 列，每格约 0.6m。
- **材质**：无光照自发光（Unlit），保证任意光照下清晰可见，`checker_white` 高对比。
- **两侧立柱**：可选，红白条纹小立柱作为通过参照。

## 状态颜色汇总
| 状态 | 计时器色 | 徽标 | 圈数文案 |
|------|---------|------|----------|
| READY | `primary` | `neutral` 灰白 | 第 1 圈 |
| RACING | `primary`(呼吸) | `primary` | 第 1 圈 · 计时中 |
| FINISHED | `success` | `success` | 已完成 1 圈 |
## 精灵图规格
1. 起终点线棋盘格精灵（tex_checker_finish）：单帧静态贴图，512x64，2 行 8 列黑白格，无缝横向平铺，Unlit 自发光材质。

2. 状态徽标呼吸光点：3 帧循环（缩放 1.0 → 1.35 → 1.0），帧时长 120ms，尺寸 12x12，用于 RACING 状态计时器左侧圆点脉冲。

3. 「GO / FINISH」提示字精灵：2 帧（入场 100% 不透明 → 全透明），各 512x128 含辉光描边，入场 400ms 停留后 160ms 淡出，`family_display` 大号字。

4. 通过线两侧立柱条纹（可选）：静态 128x256 红白斜条纹贴图，用于起终点参照柱。
