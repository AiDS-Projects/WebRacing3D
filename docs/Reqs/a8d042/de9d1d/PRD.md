# PRD — 实现玩家赛车与第三人称跟随视角

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 用户故事
As a 玩家，I want to 驾驶一辆赛车并在第三人称跟随视角下观察车辆与赛道，So that 我能直观判断车速、方向与赛道位置，通过键盘或触屏完成加减速与转向操作，为后续计时跑圈玩法提供可控的驾驶体验。

## 功能需求
1. 玩家赛车模型：使用 Three.js 基础几何体（Box/Cylinder/Sphere）组合构建低多边形赛车，包含车身与 4 个车轮，车头朝向可明显区分（如车头更尖或颜色标记）；赛车放置在赛道起点。
2. 第三人称跟随相机：相机位于赛车后方偏上位置，实时跟随赛车的位置与朝向；相机位置采用平滑插值（lerp），避免转向时抖动或瞬时跳变；相机始终朝向赛车前方视点。
3. 键盘输入：W/↑ 加速、S/↓ 刹车/倒车、A/D/←/→ 转向；支持多键同时按下（如 W+A 同时前进转向）；键释放后对应状态立即复位。
4. 触屏虚拟按键：移动端屏幕显示 4 个虚拟按键（油门、刹车、左转、右转），支持多点触控同时按下多个按键；按键按下/松开事件分别映射到与键盘相同的输入状态。
5. 输入系统架构：沉淀统一输入状态管理模块（InputState），键盘与触屏写入同一份状态（throttle/brake/steer），赛车物理与相机只读取该状态，避免输入逻辑散落。

## 验收标准
- [ ] 页面加载完成后，场景中可见玩家赛车，车头朝向与初始行进方向一致，误差 ≤ 5°。
- [ ] 按下 W 键后，赛车在 300ms 内开始加速前进，速度从 0 持续增加。
- [ ] 松开 W 键后，赛车速度在 1s 内开始下降（存在减速度），最终减速至 0。
- [ ] 按住 A 或 D 键时，赛车以设定角速度转向（转向响应延迟 ≤ 100ms），松开后转向角速度归零。
- [ ] 同时按住 W 与 A（或 W 与 D）时，赛车同时前进并转向，前进与转向互不阻塞。
- [ ] 相机与赛车的相对距离保持固定（初始设定值 ± 5%），赛车直线行驶时相机不发生明显抖动（偏移 < 0.1 单位）。
- [ ] 赛车转向时，相机在 300ms 内完成朝向跟随并稳定（无持续振荡）。
- [ ] 触屏设备上显示 4 个虚拟按键（油门、刹车、左转、右转），单个按键尺寸 ≥ 48×48px。
- [ ] 触屏同时按下「油门 + 左转」两个按键时，赛车执行前进 + 转向，多点触控无冲突。
- [ ] 键盘与触屏输入同时使用时不互相干扰，任一输入方式均可独立完成前进/刹车/转向。
- [ ] 驾驶过程中帧率保持 ≥ 55fps（目标 60fps），无明显卡顿。

## 边界条件（不做的事）
不包含：真实车辆碰撞物理（车与车、车与障碍物刚体碰撞，边界减速由后续工单处理）；
不包含：赛道计时、圈数检测、单圈成绩结算（后续工单）；
不包含：高精度赛车模型、PBR 材质与贴图（仅低多边形基础几何体）；
不包含：音效、背景音乐、引擎轰鸣声；
不包含：手机陀螺仪/重力感应转向；
不包含：AI 对手车辆、多人联机；
不包含：车辆悬挂、翻车等高级物理模拟。

## 资产需求线索
3D 模型：低多边形赛车（车身 + 4 轮，可由 Three.js 几何体程序化组合，无需外部模型文件）；
贴图：车身基础纯色/简单双色区分车头朝向（可选，可为空）；
图标：触屏虚拟按键 4 个（油门、刹车、左转、右转），简单几何图形或文字标签；
音效：暂无；
动画：车轮滚动旋转动画（可选，与车速关联，可后续补充）；
粒子特效：暂无。
