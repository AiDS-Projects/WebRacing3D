# 视觉规范 — 实现玩家赛车与第三人称跟随视角

> 所属需求：WebRacing3D 可玩原型 — 核心玩法验证

## 整体风格
整体采用现代竞速手游风格：全屏 3D 场景配合半透明玻璃拟态的触屏 HUD，按键以高饱和语义色（绿=加速、红=刹车、蓝=转向）区分功能，配合细白描边与柔和投影营造可点按的物理质感。赛车模型使用高饱和橙红车身以在深灰场景中形成视觉焦点，确保玩家一眼锁定车辆姿态。桌面端保持纯净全屏画面，仅移动端渲染虚拟按键，信息密度低、无冗余元素。

## 组件视觉规范

## 组件视觉规格

### 1. 触屏虚拟按键（通用）
- 形状：转弯键圆形、加速/刹车键圆角矩形
- 尺寸：加速键直径 88px（主键面积最大）；刹车键直径 64px；左/右转键直径 72px
- 背景：`rgba(255,255,255,0.14)`，边框 2px `rgba(255,255,255,0.35)`
- 图标：白色 `#FFFFFF`，图标尺寸 28px
- 按下态：scale 0.92，背景提升至 `rgba(255,255,255,0.30)`，阴影减弱为 `0 1px 3px rgba(0,0,0,0.55)`

### 2. 加速按键
- 颜色语义：绿 `#22C55E` 半透明叠加（`rgba(34,197,94,0.35)`）
- 图标：向上箭头
- 位置：屏幕右下，刹车键正上方

### 3. 刹车/倒车按键
- 颜色语义：红 `#EF4444` 半透明叠加（`rgba(239,68,68,0.35)`）
- 图标：向下箭头
- 位置：屏幕右下，加速键正下方

### 4. 左转 / 右转按键
- 颜色语义：蓝 `#3B82F6` 半透明叠加（`rgba(59,130,246,0.35)`）
- 图标：向左 / 向右箭头
- 位置：左下（左转）、右下（右转，位于加速/刹车左侧）

### 5. HUD 容器
- 覆盖层：全屏透明 `rgba(0,0,0,0.0)`，pointer-events: none；按键自身 pointer-events: auto
- 布局：左下 1 键 + 右下 3 键（右转、加速、刹车），符合赛车手游拇指习惯

### 6. 状态占位区（预留，本工单不实现）
- 位置：顶部居中
- 样式：背景 `rgba(0,0,0,0.35)`、圆角 8px、文字白色 14px、内边距 8px

### 7. 3D 场景（参考，非 HUD）
- 赛车车身：橙红 `#E85D3A`（竞速感）；驾驶舱深灰 `#374151`；车轮黑 `#111827`、轮毂灰 `#9CA3AF`
- 地面：深灰 `#1F2937`（占位，赛道属其他工单）
## 精灵图规格
无精灵图需求。本工单赛车由 Three.js 基础几何体（Box/Cylinder/Sphere）组合构建，无帧动画精灵；HUD 按键采用矢量图标（iconify outline），无需位图精灵。
